# KP Jump

Расширение для браузера: на странице фильма или сериала на [Кинопоиске](https://www.kinopoisk.ru) появляется кнопка, которая открывает выбранный вами сервис (TMDB, IMDb, Letterboxd, JustWatch) или **вашу собственную ссылку-шаблон**.

## Возможности

- Кнопка «Смотреть» (текст можно изменить) на страницах `/film/…` и `/series/…`
- Готовые сервисы: TMDB, IMDb, Letterboxd, JustWatch
- **Свой шаблон ссылки** с плейсхолдерами
- Опция «добавлять год к названию»
- Открытие в новой или текущей вкладке

## Свой шаблон ссылки

В настройках выберите **«Свой шаблон…»** и введите адрес. Доступные плейсхолдеры:

| Плейсхолдер | Значение |
|-------------|----------|
| `{title}`   | название (с годом, если включена опция) |
| `{year}`    | год выпуска |
| `{kp_id}`   | ID фильма на Кинопоиске |
| `{type}`    | тип страницы: `film` или `series` |
| `{kp_path}` | путь на Кинопоиске: `film/258687` или `series/258687` |

Значения подставляются в URL-кодировке. Шаблон должен начинаться с `http://` или `https://`.

Примеры:

```
https://www.themoviedb.org/search?query={title}
https://example.com/search?q={title}&year={year}
https://www.kinopoisk.ru/{type}/{kp_id}/
```

Под полем ввода показывается пример готовой ссылки.

## Установка в Chrome (и Edge, Brave, Opera)

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте в постоянную папку (после установки её нельзя удалять или переносить).
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (справа вверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой лежит `manifest.json`.
5. Закрепите значок расширения (иконка-пазл → булавка) и нажмите на него — откроются настройки.
6. Откройте страницу фильма на Кинопоиске (при необходимости обновите её через F5) — справа внизу появится кнопка.

## Установка в Firefox

В репозитории два манифеста: `manifest.json` (Chrome) и `manifest.firefox.json`. Для Firefox:

1. Переименуйте `manifest.json` в `manifest.chrome.json`, а `manifest.firefox.json` — в `manifest.json`.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение…** и выберите файл `manifest.json`.

Временное дополнение удаляется после перезапуска Firefox. Для постоянной установки его нужно подписать через [addons.mozilla.org](https://addons.mozilla.org/developers/).

## Структура

| Файл | Назначение |
|------|-----------|
| `manifest.json` | манифест (Chrome, MV3) |
| `manifest.firefox.json` | манифест для Firefox |
| `presets.js` | список сервисов, сборка и проверка ссылки |
| `content.js` | кнопка на странице Кинопоиска |
| `options.html`, `options.js` | страница настроек |
| `background.js` | открытие настроек по клику на значок |
